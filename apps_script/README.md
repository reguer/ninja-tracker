# Apps Script (Opcional)

Archivo: `Code.gs`

Incluye:
- Menu `Ninja Tracker`
- Importacion CSV para `Actividades`, `Proyectos`, `FasesProyecto`, `EventosDiversion`
- Mapeo por columnas (preserva columnas de formula)
- Validacion de encabezados obligatorios
- Refresh de dashboard

Uso rapido:
1. Abrir Google Sheet.
2. `Extensions > Apps Script`.
3. Pegar `Code.gs`.
4. Guardar y recargar.
5. Usar menu `Ninja Tracker`.
